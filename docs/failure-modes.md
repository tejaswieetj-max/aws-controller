# SPENDCTL failure behavior

“Expected behavior” below means source behavior covered locally. It is not a claim about live AWS behavior. The invariant is `budget_micro = available_micro + reserved_micro + spent_micro`.

| Failure/injection | Implemented behavior and recovery | Invariant impact | Local evidence | Remaining gap |
|---|---|---|---|---|
| Duplicate request | Same team/period/key/fingerprint returns the durable reservation; retry uses same identity. | Hold is counted once. | `tests/unit/test_api.py::test_create_request_idempotency_and_conflict`; `tests/unit/test_ledger.py::test_budget_create_and_reserve_replay_are_idempotent` | No live API/DynamoDB retry observed. |
| Conflicting idempotency payload | Fingerprint mismatch is rejected; caller must use a new key for a genuinely new request. | Existing hold is unchanged. | `tests/unit/test_api.py::test_create_request_idempotency_and_conflict`; `tests/unit/test_ledger.py::test_conflicting_idempotency_reuse_and_reservation_id_conflict` | API Gateway/JWT end-to-end not exercised. |
| Ambiguous workflow start | Deterministic execution name is listed/described and input compared; unresolved outcome remains unknown and held. Recovery uses same identity; no blind release. | Reserved remains reserved. | `tests/unit/test_api.py::test_ambiguous_workflow_start_stays_unknown_and_keeps_reservation`; `tests/unit/test_core.py::test_timeout_with_no_visible_execution_remains_unknown_and_held` | Real Step Functions timeout/recovery not exercised. |
| EC2 launch failure | Provisioner can inject failure before EC2 call. Pre-launch release requires durable failure, `NOT_CREATED`, and no resource identities. Post-launch failure needs confirmed cleanup before settlement. | Confirmed no-resource path returns reserve; otherwise hold remains until safe resolution. | `tests/unit/test_provisioner.py::test_failure_injection_is_explicit_and_occurs_before_launch`; `tests/unit/test_ledger.py::test_prelaunch_workflow_failure_release_requires_durable_no_resource_evidence` | No real RunInstances/DryRun was performed in this evidence task. |
| Unknown instance state | Reaper records cleanup `UNKNOWN`, alerts, and does not terminate if ownership/resource state cannot be established. Retry/sweeper can revisit. | Hold remains reserved. | `tests/unit/test_lifecycle.py::test_ownership_mismatch_never_terminates_and_creates_deduplicated_alert`; `test_unknown_start_reconciles_same_identity_and_never_releases_when_resources_unknown` | AWS EC2 state and ownership behavior unverified. |
| Cleanup failure | Retryable EC2 error persists unknown cleanup and raises; periodic sweeper retries. No refund on pending/unknown cleanup. | Hold remains reserved. | `tests/unit/test_lifecycle.py::test_cleanup_failure_keeps_hold_reserved_and_retries`; `tests/unit/test_ledger.py::test_partial_or_unknown_cleanup_never_refunds` | Real scheduler/EventBridge/EC2 cleanup unverified. |
| Duplicate lifecycle event | Stable event/settlement identities and conditional transitions make replay idempotent; termination is not repeated after recorded completion. | No second balance movement. | `tests/unit/test_lifecycle.py::test_cancel_reaper_marks_cancelled_and_retries_cleanup_without_double_settlement`; `test_expiry_reaper_terminates_owned_instance_then_provisionally_settles_once` | Event delivery ordering/duplication not exercised in AWS. |
| Duplicate or revised CUR records | Same record identity and fingerprint is deduplicated; conflicting duplicate identity fails closed. Newer revision applies a delta; same reconciliation replays; stale ordering is rejected. | Delta moves available/spent equally; invariant remains. | `tests/unit/test_billing.py::test_reconcile_attribution_revision_and_duplicate_are_atomic`; `test_concurrent_same_snapshot_is_applied_once` | Real CUR schema/manifest/revision order and AWS billing attribution unverified; reconciliation remains disabled by default. |
| Invariant mismatch | Checker recomputes budget totals, records an alert and publishes `InvariantViolation`; repeated checks deduplicate alert identity. | It detects/alerts; it does not silently repair the budget. | `tests/unit/test_invariants.py::test_checker_recomputes_reservations_and_emits_deduplicated_alert` | Real scheduled checker and event delivery unverified. |
