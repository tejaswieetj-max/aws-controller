## Known limitations

- Application ledger budget is not an AWS billing cap.
- Fixture/fallback pricing must be identified; it is not an account invoice.
- Successful cleanup currently makes a conservative provisional settlement from the full hold until final billing data arrives.
- CUR export/table/tag setup and live schema/attribution verification remain external/manual; gate defaults off.
- Current account access, network inputs, cost exposure, and deployment prerequisites require fresh owner-approved checks.
- Local mocks and tests do not prove IAM evaluation, service quotas, real event delivery, resource cleanup, or browser authentication.
