# SPENDCTL reproducible demo scenarios

All commands below are local and use tests/mocks unless explicitly marked live. Run from the project root with `.venv` installed. Test scenarios do not contact AWS. The successful admission artifact is generated by `PYTHONPATH=services .venv/bin/python scripts/evidence_idempotency_demo.py` and saved to [`review/evidence/idempotency-demo.json`](../review/evidence/idempotency-demo.json). No live scenario is currently AWS verified.

| Scenario | Prerequisites and input | Expected result | Local test command | Evidence |
|---|---|---|---|---|

Admission service alone does not start workflow. | `PYTHONPATH=services .venv/bin/python scripts/evidence_idempotency_demo.py`; `PYTHONPATH=services .venv/bin/python -m pytest -q tests/unit/test_pricing_admission.py::test_admission_reserves_atomically_and_replay_is_durable` | `review/evidence/idempotency-demo.json`; pytest output |
